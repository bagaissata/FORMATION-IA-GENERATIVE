    Aide & raccourcis

    Saisie

    • , est la virgule décimale française : 1,5 + 2.
    • ; sépare les arguments : log(8; 2), combinations(5; 2).
    • La multiplication implicite est acceptée : 2π, 3(4+5), 2sin(30).
    • % est contextuel : 200+10% = 220, 200×10% = 20, 8%3 = 2.

    Fonctions

    • log = base 10, ln = népérien, log(x; b) = base personnalisée.
    • nCr → combinations(n; k), nPr → permutations(n; k).
    • i est l'unité imaginaire ; re, im, arg, conj, abs sont disponibles.

    Clavier

    • Entrée calcule et ajoute à l'historique.
    • Échap efface la saisie ; Ctrl+Retour arrière efface tout.
    • ? ouvre cette aide. Ctrl+C / V fonctionnent normalement.

    Mémoire et matrices

    • M+, M−, MR, MC agissent sur les résultats scalaires.
    • Les matrices se saisissent dans l'onglet Matrices (2×2 à 4×4), sans syntaxe texte.
    • ans contient le dernier résultat et peut être une matrice.
